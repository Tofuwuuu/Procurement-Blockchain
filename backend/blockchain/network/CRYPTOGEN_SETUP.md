# Hyperledger Fabric Certificate Generation Guide

## Problem
The peer containers are failing with `panic: runtime error: index out of range [1]` in `sanitizeCert`. This happens because Hyperledger Fabric expects certificates signed by a CA certificate, not self-signed certificates.

## Solution: Use Official cryptogen Tool

The official Hyperledger Fabric `cryptogen` tool generates certificates in the exact format Fabric expects.

### Option 1: Download cryptogen (Recommended)

1. **Download cryptogen for Windows:**
   - Go to: https://github.com/hyperledger/fabric/releases
   - Download the latest Fabric 2.5.x release
   - Extract `cryptogen.exe` from the `bin` folder
   - Place it in `backend/blockchain/network/scripts/` or add to PATH

2. **Create crypto-config.yaml:**
   ```yaml
   OrdererOrgs:
     - Name: Orderer
       Domain: example.com
       Specs:
         - Hostname: orderer
   
   PeerOrgs:
     - Name: Org1
       Domain: org1.example.com
       EnableNodeOUs: false
       Template:
         Count: 2
       Users:
         Count: 2
   
     - Name: Org2
       Domain: org2.example.com
       EnableNodeOUs: false
       Template:
         Count: 2
       Users:
         Count: 2
   ```

3. **Generate certificates:**
   ```powershell
   cd backend\blockchain\network
   .\scripts\cryptogen.exe generate --config=./crypto-config.yaml --output=./crypto-config
   ```

### Option 2: Use Docker to run cryptogen

If you can't download cryptogen directly:

```powershell
cd backend\blockchain\network

# Create crypto-config.yaml (see above)

# Run cryptogen in Docker
docker run --rm -v ${PWD}:/work -w /work hyperledger/fabric-tools:2.5 cryptogen generate --config=./crypto-config.yaml --output=./crypto-config
```

### Option 3: Use Fabric CA (Advanced)

For production-like setup, use Fabric CA:

```powershell
# Start Fabric CA server
docker-compose -f docker-compose-ca.yml up -d

# Enroll admin and register peers
# (See Fabric CA documentation)
```

## After Generating Certificates

1. **Fix MSP structure** (if needed):
   ```powershell
   python scripts\fix_msp_structure.py
   ```

2. **Restart containers:**
   ```powershell
   docker-compose -f docker-compose-fabric.yml down
   docker-compose -f docker-compose-fabric.yml up -d
   ```

3. **Verify:**
   ```powershell
   docker logs peer0.org2.example.com
   ```

## Current Issue

The self-signed certificates generated by the Python script don't match Fabric's strict requirements. The `sanitizeCert` function expects:
- Certificates signed by a CA
- Proper certificate chain
- Specific Subject DN format
- Proper X.509 extensions

## Quick Fix (Temporary)

If you need a quick workaround for development, you can:
1. Use the official Fabric samples network as a reference
2. Copy their crypto-config structure
3. Or use a pre-configured Fabric network Docker image
